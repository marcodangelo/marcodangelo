# Marco D’Angelo

My work focuses on international partnerships and open source ecosystems, with a background at Microsoft and Huawei. I founded Radixia to bring that experience into a business I am directly responsible for.

Here I share personal technical experiments, prototypes and occasional contributions. Some explore practical questions arising while building Radixia.

## Selected personal experiments

- [MCP Census](https://github.com/radixia/mcp-census): measuring how MCP services can be discovered, with published evidence and explicit methodological limitations.
- [EmDash references benchmark](https://github.com/marcodangelo/emdash-references-bench): investigating database-query overhead when loading related content, with a reproducible benchmark and an experimental batching approach.
- [Radixia Blog MCP](https://github.com/radixia/blog-mcp): exploring read-only access to articles and conference transcripts through MCP.
- [Radixia Brand](https://github.com/radixia/brand): shared styles, design tokens and documentation for Radixia’s web projects.

Older repositories include historical Azure examples and learning exercises.
